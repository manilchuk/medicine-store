# Medicine Store — Admin Dashboard

Адміністративна панель медичного магазину.

## Структура

- `client/` — React (Vite) фронтенд
- `server/` — Node.js + Express + MongoDB бекенд

## Швидкий старт

### Клієнт

```bash
cd client
npm install
cp .env.example .env
npm run dev

```

### Сервер

```bash
cd server
npm install
cp .env.example .env
npm run dev

```

### Технології

Frontend: React, Vite, React Router, React Query, React Hook Form, Yup, MUI, CSS Modules, Inter
Backend: Node.js, Express, MongoDB, Mongoose, JWT
